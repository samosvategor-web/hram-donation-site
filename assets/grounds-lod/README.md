# LOD-ассеты благоустройства храма — интеграция в виджет прогулки

Исходная модель `TEMPL_GP_BASE_001A.glb` (711 МБ) оптимизирована в **6 файлов GLB, каждый < 20 МБ**.
Скульптуры — в полном качестве (остаются гладкими при приближении), деревья и окружение упрощены.
Формат: **meshopt-геометрия + KTX2/Basis-текстуры** (DRACO не используется).

## Файлы (рядом с этим README)

| Файл | МБ | Что это | Загрузка | Мировой центр [x, y, z] |
|---|---|---|---|---|
| `site.glb` | 19.3 | земля, мощение, постройки, контекст | всегда | [21.6, 15.2, -0.5] |
| `vegetation.glb` | 19.4 | деревья / листва | всегда | [3.2, 5.9, -1.9] |
| `ksenia.glb` | 12.1 | скульптура: св. Ксения с детьми | по близости | [-29.8, 1.1, -17.0] |
| `angel.glb` | 13.1 | скульптура: золочёное навершие-колонна | по близости | [5.6, 1.2, -13.2] |
| `lion.glb` | 9.4 | скульптура: лев | по близости | [-3.3, 0.7, -14.1] |
| `eagle.glb` | 9.0 | скульптура: орёл | по близости | [-7.0, 1.4, -14.7] |

## Как собрать LOD

1. Все файлы **выровнены в мировых координатах** → грузить каждый и добавлять в сцену
   **без смещений** (identity-трансформа); объекты встают на свои места.
2. `site.glb` + `vegetation.glb` грузить сразу (всегда видны). Скульптуры — подгружать
   по близости камеры к их центрам (для простого старта можно грузить все 6 сразу, ~82 МБ).
3. **Загрузчик three.js обязан включать `KTX2Loader` и `MeshoptDecoder`** — иначе текстуры/
   геометрия не декодируются:
   ```js
   const ktx2 = new KTX2Loader()
     .setTranscoderPath('<three>/examples/jsm/libs/basis/')
     .detectSupport(renderer);            // renderer должен уже существовать
   const loader = new GLTFLoader()
     .setKTX2Loader(ktx2)
     .setMeshoptDecoder(MeshoptDecoder);
   ```

## Важно
- Скульптуры **не пересжимать и не объединять** в один файл — квантование привязано к bbox
  файла, при объединении/огрублении появляется огранка (поэтому каждая — отдельным файлом).
- Грузить GLB по http(s) (не `file://`).

Остальное (точки стриминга, прогресс-бар, материалы) — по коду конкретного виджета.
